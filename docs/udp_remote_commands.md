### 基本
- ポート番号: 5000 (UDP)		
- 文字コード: UTF-8		
判定: 大文字・小文字は区別しません（MUTE ON でも mute on でもOK）。
末尾: 改行コード（\n）があってもなくても動作するように作ってあります。		
### コマンド

| 機能          | コマンド (文字列)    | 備考                |
| ----------- | ------------- | ----------------- |
| 一括電源 ON     | all power on  | 登録全台の電源を入れます      |
| 一括電源 OFF    | all power off | 登録全台の電源を切ります      |
| 一括ミュート ON   | mute on       | 登録全台を消音/映像遮断します   |
| 一括ミュート OFF  | mute off      | 登録全台のミュートを解除します   |
| プリセット実行     | p1 ～ p10      | 保存した各プリセットを呼び出します |
| プリセット実行(別名) | preset 1 ～ 10 | 上記と同じ動作です         |
